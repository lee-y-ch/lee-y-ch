# 이용찬

백엔드 개발과 클라우드 운영을 하고 있습니다.

여담에서는 AWS 인프라와 배포, 운영을 맡았고, DB 이전 중 요청과 인증 상태를 보존하는 과정을 시험했습니다. 모찌에서는 저장한 기록을 다시 찾는 검색, 채팅과 색인 경로를 개선하고 있습니다.

## 프로젝트

- **[여담](https://github.com/100-hours-a-week/KTB4-2nd-Cloud)** — 여행 사진 정리 서비스. AWS 인프라, CI/CD, 운영 관측과 DB 이전 리허설을 담당했습니다.
- **[모찌](https://github.com/dku-mochi/mochi)** — 스크린샷이나 링크, 메모를 저장하고 다시 찾는 서비스. 백엔드 검색과 채팅, 색인 개선을 맡고 있습니다.
- **[LEO PHOTO](https://github.com/lee-y-ch/community-backend)** — 사진 커뮤니티 개인 프로젝트. API를 개발하고 검색, 조회수 집계와 이미지 처리 경로를 개선했습니다.
